Quick Toggle Layer Manual

Quick Toggle Layer allows you to assign and toggle the visibility of up to 3 independent layers or Group Folders (such as reference folders, rough sketch groups, lineart, color palettes, or values check layers) instantly using dedicated keyboard shortcuts — without interrupting your drawing or leaving your active layer.

✨ Key Features

  • Full Group / Folder Support: Pin entire Group Layers to toggle multiple layers at once with a single shortcut.
  • Smart Hierarchy Management: If you toggle a layer inside a hidden group, the parent group is automatically unhidden so your layer is immediately visible.
  • 3 Independent Slots: Maintain up to 3 separate quick-toggle slots simultaneously.
  • Zero Workflow Interruption: Keep painting on your active layer while toggling helper layers and groups in real-time.
  • On-The-Fly Pinning: Select any layer or group, press your "Set" shortcut, and Krita remembers it immediately.
  • Name Tag Auto-Detection: Fallback support for layers or groups tagged with [1], [2], [3] or #1, #2, #3.

⌨️ Recommended Shortcut Configuration

Go to Settings > Configure Shortcuts... and search for Quick Toggle:

Action Name Suggested Hotkey Description
Quick Toggle: Set Current Layer/Group as Slot 1 Shift + 1 Assigns the active layer or group folder to Slot 1.
Quick Toggle: Toggle Layer/Group 1 1 Toggles visibility of Slot 1 on/off.
Quick Toggle: Set Current Layer/Group as Slot 2 Shift + 2 Assigns the active layer or group folder to Slot 2.
Quick Toggle: Toggle Layer/Group 2 2 Toggles visibility of Slot 2 on/off.
Quick Toggle: Set Current Layer/Group as Slot 3 Shift + 3 Assigns the active layer or group folder to Slot 3.
Quick Toggle: Toggle Layer/Group 3 3 Toggles visibility of Slot 3 on/off.
Tip for Groups: You can create a Group named #1 containing all your reference images, sketches, and color guides. Pressing 1 will show/hide the whole folder together!

🎨 How to Use with Groups

  1. Click on any Group Folder in your layers panel.
  2. Press Shift + 1. The status bar will confirm: "Quick Toggle: Group 'References' set to Slot 1".
  3. Go back to your active drawing layer.
  4. Press 1 at any time to hide or show the entire group folder and all its contents instantly!
